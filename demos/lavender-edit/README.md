## Purpose
A standalone, portfolio-grade editorial beauty website concept in soft lavender. The freebie for December is a **different product and page**; it shares source imagery but not the website workflow. This demo is not a live ecommerce store, and contains no fictional pricing, reviews or product-performance claims.

## Brand direction
- Palette: muted lavender, mauve, warm ivory, deep aubergine and soft beige.
- Type: oversized elegant display serif paired with restrained modern sans.
- Layout: commanding hero, generous whitespace, art-directed one-photo-per-frame sections, mobile-first experience.
- Motion: subtle hover and entrance transitions with reduced-motion support.
- Interactions: mobile navigation, image lightbox, English/Spanish selector, accessible keyboard handling.
- Footer: Powered by The Launch Era.

## Master reconstruction brief
Create a polished, responsive, standalone beauty campaign demo titled **The Lavender Edit**, written in natural English with a Spanish selector. The hero must feature an elegant, full-height lavender perfume visual and large elegant editorial typography, followed by a photographic campaign gallery, a storytelling section, intimate texture imagery and seasonal gift artwork. Use the eight supplied original images exactly as standalone assets; never merge them into one collage, invent extra labels or modify the artwork. Do not add made-up products, features, discounts, checkout functionality, certifications, ingredients, reviews or testimonials. All call-to-action buttons must navigate to real sections, with smooth mobile behavior and clear touch targets. Keep a discreet note that the page is a visual concept, and a footer that says Powered by The Launch Era.

### Rebuild steps
1. Use this folder's `index.html` as the static standalone page.
2. Keep the eight images in the `assets/` folder with exactly the filenames above.
3. Open `index.html` directly or serve the folder from any static server. No compilation required.
4. To republish to GitHub Pages, commit changes under `demos/lavender-edit/` on `main`. The existing GitHub Action copies this folder to `_site/lavender-edit/` and performs smoke tests.
5. Verify the public URL, all eight images, navigation links, Spanish language toggle, and keyboard-close lightbox.
