# Jaramillo Boutique — editorial fashion demo

Responsive bilingual (EN/ES) boutique showcase in HTML, CSS and vanilla JavaScript. **No checkout.** This is a design concept, not an inventory or offer.

## Preview

Open `index.html` in a browser, or serve with `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Unique hero

`assets/model-cutout.webp` is a transparently masked model photo, placed **above the background panel** with `overflow: visible`. The top of the model extends above the beige hero scene for the desired magazine effect. All photos are local WebP assets; the ZIP is complete and works without external image hosts.

## Before sharing publicly

- Confirm the designer's name and approved bio. The designer portrait uses the original photograph, not the separate campaign model.
- Replace generated concept looks with actual merchandise and validate product size availability. S / M / L / XL in the site is marked unverified.
- Confirm each of the three store addresses, hours and contact routes.
- Test on an actual phone and ensure photography permissions for commercial use.
- No fictitious product pricing, shipping claims or online payment functionality.
