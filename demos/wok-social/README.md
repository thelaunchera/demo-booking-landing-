# WOK SOCIAL — Chinese Street Kitchen (Original Demo)

An original editorial, mobile-first concept website for a fictional Chinese street-kitchen restaurant. Created for The Launch Era's demo portfolio, using GitHub Pages only (no AppDeploy).

## Preview
After a successful GitHub Pages workflow deployment:
https://thelaunchera.github.io/demo-booking-landing-/wok-social/

## Files
- index.html — content, semantics and layout
- styles.css — brand palette, bold typography, responsive design and mini-tags
- script.js — mobile menu, accessible dish dialogs, category filters, image fallback
- favicon.svg / food-placeholder.svg — original inline vector assets

## Brand direction
- Concept brand: WOK SOCIAL (fictional, not an actual business).
- Palette: wok red #E32620; ink #171615; acid yellow #FFE400; warm cream #F6F1E7.
- Fonts: Caprasimo + DM Sans, both from Google Fonts.
- Visual system: colored slanted mini-tags, small grids, oversized rounded display type, food-first photography.
- Food images: links to Unsplash stock image CDN for temporary concept presentation; images are not owned, copied, or bundled. Original SVG fallback used when external images are unavailable.
- All dishes are illustrative; no pricing, bookings, payment, orders, address, hours, or real restaurant claims.

## UX checks
- Responsive from 320px up.
- Category filtering for 6 sample dishes.
- Non-transactional details modal with Esc/backdrop/keyboard operation.
- Reduced motion preference and visible focus indicators.
- Editorial footer credits The Launch Era.
